# iPhone screenshots

These are native SwiftUI screens from this repository, captured on a dedicated iPhone Simulator
on **29 October 2026** using synthetic demo records. They show the audited iPhone redesign and
its subsequent Your Cards/spacing work. Screens and editor routes were opened individually for
visual review, so most captures omit the root tab bar.

The captures contain illustrative metrics and imported-source labels. They do not contain the
owner's health history, account details, or device identifiers, and do not establish sensor accuracy
or hardware validation. The images are unmodified copies of the reviewed PNG captures, displayed
at a smaller width in the README. Each is 1206 × 2622 pixels. Their EXIF contains only color space
and image dimensions; no PNG text, GPS, or account metadata is present.
